# Elect Cleaning Services — Website Redesign

A complete, from-scratch redesign of electcleaning.com built with vanilla HTML, CSS and JavaScript.
No build step, no frameworks, no external APIs — open `index.html` and it runs.

## Design notes

- Palette: deep navy ink `#0b2942`, teal brand `#0d8a9b`, mint accent `#2fd6b4`.
- Typography: Plus Jakarta Sans with a system-font fallback stack.
- Fully responsive down to 360px, with a mobile sticky call/quote bar.
- Semantic HTML5 landmarks, skip link, visible focus states, descriptive alt text,
  `prefers-reduced-motion` support.
- SEO: meta description, Open Graph/Twitter cards, canonical URL and
  `HomeAndConstructionBusiness` JSON-LD structured data.

## Imagery

Authentic photography from the original site is preserved (owner/crew at work, service
photos, before-and-after job shots, logo and Google Reviews badge). Generic stock artwork
found on the old site was replaced with contextually matched Pexels photography for the
hero, move-out cleaning, commercial, service-area and article sections.
